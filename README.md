# mncs-signal

Machine-native signal processing for MNCS.

`mncs-signal` combines mathematical transforms with streaming and real-time execution, making it a strong pressure project for complex arithmetic, SIMD, buffers, latency, deterministic scheduling, CPU/GPU kernels and ergonomic composition in `mncs-language`.

## Initial scope

- sampled signal/timebase abstractions
- complex numbers and FFT/IFFT
- convolution and correlation
- FIR/IIR filters
- resampling and interpolation
- spectral analysis and windows
- streaming/ring-buffer pipelines
- fixed/float numeric modes and verification
